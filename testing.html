Tests & coverage

Quality is part of
the public API.

One canonical registry assigns every test once to Unit, Functional, Behavioral, Integration, or Regression. vanilla-test 2.1.0 runs it directly and collects native V8 coverage, while older supported Node releases use the local compatibility adapter. A shared Given/When/Then inventory also proves the bare package import in Node and real Chrome.

strong-type works with bundlers and without a bundler. Bundlers resolve bare imports normally; native browser ESM uses an explicit import map with no build or transpilation step.

The native-browser fixture keeps this complete npm-layout import map before its module script:

HTML
<script type="importmap">
{
    "imports": {
        "strong-type": "./node_modules/strong-type/index.js"
    }
}
</script>

<script type="module">
    import Is from 'strong-type';
    console.log(new Is(false).string('native ESM'));
</script>

Those mapped paths are relative to the HTML document. The app must be served over HTTP(S), and its server must expose the files; file:// is unsupported. There are no runtime dependencies, so this map needs no dependency entries or nested-version scopes.
