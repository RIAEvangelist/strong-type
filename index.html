Native by design

Nothing between your code and JavaScript.

There is no runtime dependency tree, CommonJS copy, transpiler, framework, or bundle. The optional Node adapter imports only built-in Node modules and never enters the default import graph.

02 · Quick start

Use the runtime directly.

JavaScript
import Is from 'strong-type';

const is=new Is;
const weakIs=new Is(false);

is.string('strong-type');        // true
weakIs.number('42');             // false
is.union(new Map,'map|set');     // true

is.number('42');                 // throws TypeError

05 · Complete reference

Every validator, explained.

Every method exists in every runtime. A guarded type that the host does not provide throws in strict mode and returns false in non-strict mode—never a missing-global ReferenceError.

06 · Core methods

Build checks in the same style.

07 · Unions

Accept one of several named validators.

JavaScript
is.union('type','string|number');
is.union(42,['string','number']);

// Spaces are trimmed. Custom and Node validators work.
nodeIs.union(Buffer.from('type'),'buffer|string');
Validator names are resolved only from the strong-type prototype chain. Inherited Object methods such as toString and multi-argument helper methods are rejected.

08 · Node adapter

Node precision stays opt-in.

The adapter extends the same Is class. It imports only node:util, node:stream, node:events, and node:crypto. The browser playground intentionally never loads it.

Node JavaScript
import IsNode from 'strong-type/node';

const is=new IsNode;

is.buffer(Buffer.from('type'));
is.proxy(new Proxy({},{}));
is.nodeReadable(process.stdin);

09 · Extend

Your own types stay first-class.

JavaScript
import Is from 'strong-type';

class Pizza{}

class MyIs extends Is{
    pizza(value){
        return this.instanceCheck(value,Pizza);
    }
}

const is=new MyIs;
is.pizza(new Pizza);
is.union(new Pizza,'pizza|string');
